## 12. Methodology notes

- **Multi-label expected intents**: a single-class classifier evaluated against a multi-element expected set is given credit if the primary prediction is in the set. Per-label PRF (Section 5) uses a stricter accounting that counts every missed expected label as a false negative.
- **Open-now contract**: the production code returns `True` or `None`, never `False`. Diagnostic labels respect that, so `expected_open_now=None` covers both 'silent' and 'should-not-fire'.
- **Latency**: measured around `predict_intent` and `predict_category` plus the three `extract_*` methods on the QueryPlanner. Cold-start (model load) is excluded — the classifier is loaded once before the loop.
- **Instrumentation logs**: captured via a custom `logging.Handler` attached to `belem_converse.core.query_planner` at `INFO` level. Three event names are captured: `proximity_intent_detection`, `open_now_detection`, `category_detection`.
